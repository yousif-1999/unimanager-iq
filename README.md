# UniManager IQ v0.3

نسخة تجريبية موسعة لنظام إدارة الكليات والمعاهد.

## الجديد
- إدارة طلبة محسّنة وملف طالب.
- الأقساط والدفعات وسجل الدفعات.
- الأقسام والمواد.
- إدخال درجات السعي والنهائي وحساب الدرجة النهائية والنجاح/الرسوب.
- Master Sheet للتصدير إلى Excel.
- تقارير الطلبة والحسابات والدفعات والدرجات.
- جميع أرقام الإدخال تُحوّل إلى الإنجليزية 0-9.

## ملاحظة
هذه النسخة ما زالت تعمل محليًا عبر LocalStorage. لا تستخدم بيانات طلاب حقيقية قبل بناء Backend وقاعدة بيانات ومصادقة وصلاحيات آمنة.


## v0.4
- إصلاح تخطيط شريط التنقل: يبقى جانبيًا بجانب المحتوى بدل الانتقال إلى أعلى الصفحة.
- دعم أفضل للشاشات الصغيرة مع بقاء القائمة الجانبية.


## v0.5
- إعادة تصميم الواجهة بنمط لوحة إدارة احترافية.
- شريط تنقل رأسي ثابت على جانب الصفحة.
- تمييز التبويب النشط وأقسام للقائمة.
- شريط علوي للمستخدم والإشعارات.


## v0.6
- عند الضغط على أي تبويب من شريط التنقل، تظهر صفحة المعلومات الخاصة به داخل منطقة المحتوى.
- إضافة بطاقات تعريفية أعلى صفحات الطلبة والحسابات والدرجات والأقسام والتقارير.
- عرض مؤشرات خاصة بكل تبويب لتوضيح محتواه فور فتحه.


## v0.7
- نقل شريط التنقل العمودي إلى يمين الشاشة ليطابق التصميم المرجعي.
- إبقاء عناصر التنقل مرتبة عموديًا داخل الشريط الجانبي.
- جعل أشرطة الأدوات داخل الصفحات أفقية ومنظمة.
- تحسين توزيع أزرار التقارير والوصول السريع.
