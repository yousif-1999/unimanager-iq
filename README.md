# UniManager IQ v0.3

نسخة تجريبية موسعة لنظام إدارة الكليات والمعاهد.

## الجديد
- إدارة طلبة محسّنة وملف طالب.
- الأقساط والدفعات وسجل الدفعات.
- الأقسام والمواد.
- إدخال درجات السعي والنهائي وحساب الدرجة النهائية والنجاح/الرسوب.
- Master Sheet للتصدير إلى Excel.
- تقارير الطلبة والحسابات والدفعات والدرجات.
- جميع أرقام الإدخال تُحوّل إلى الإنجليزية 0-9.

## ملاحظة
هذه النسخة ما زالت تعمل محليًا عبر LocalStorage. لا تستخدم بيانات طلاب حقيقية قبل بناء Backend وقاعدة بيانات ومصادقة وصلاحيات آمنة.


## v0.4
- إصلاح تخطيط شريط التنقل: يبقى جانبيًا بجانب المحتوى بدل الانتقال إلى أعلى الصفحة.
- دعم أفضل للشاشات الصغيرة مع بقاء القائمة الجانبية.


## v0.5
- إعادة تصميم الواجهة بنمط لوحة إدارة احترافية.
- شريط تنقل رأسي ثابت على جانب الصفحة.
- تمييز التبويب النشط وأقسام للقائمة.
- شريط علوي للمستخدم والإشعارات.


## v0.6
- عند الضغط على أي تبويب من شريط التنقل، تظهر صفحة المعلومات الخاصة به داخل منطقة المحتوى.
- إضافة بطاقات تعريفية أعلى صفحات الطلبة والحسابات والدرجات والأقسام والتقارير.
- عرض مؤشرات خاصة بكل تبويب لتوضيح محتواه فور فتحه.


## v0.7
- نقل شريط التنقل العمودي إلى يمين الشاشة ليطابق التصميم المرجعي.
- إبقاء عناصر التنقل مرتبة عموديًا داخل الشريط الجانبي.
- جعل أشرطة الأدوات داخل الصفحات أفقية ومنظمة.
- تحسين توزيع أزرار التقارير والوصول السريع.


## v0.8
- تثبيت شريط التنقل داخل القائمة الجانبية بوضع عمودي في جميع أحجام الشاشة.
- منع تحوله إلى صف أفقي أو شريط تمرير أفقي.


## v0.9
- تطوير واجهة الطلبة إلى سجل احترافي.
- إضافة مؤشرات فورية لإجمالي الطلبة والصباحية والمسائية والطلبة ذوي المتبقي.
- إضافة زر تنزيل نموذج Excel للاستيراد.
- تحسين وضوح الجدول والتفاعل مع الصفوف.


## v1.0
- تطوير قسم الحسابات إلى لوحة مالية كاملة.
- إضافة الخصومات وسجل الدفعات ورقم الدفعة.
- إضافة كشف مالي قابل للاستعراض لكل طالب.
- إضافة إيصال دفع قابل للطباعة بعد تسجيل الدفعة.
- إضافة مؤشرات مالية وحالات مكتمل/جزئي/متأخر.


## v1.1
- تطوير قسم الدرجات بمرشحات الفصل ومؤشرات نجاح ورسوب ومتوسط.
- التحقق من حدود السعي (0–40) والنهائي (0–60).
- إضافة فصل للدرجة وإدخاله ضمن السجلات وMaster Sheet.
- إضافة إنشاء كشف درجات طالب قابل للطباعة.
- تحسين تصدير تقارير الدرجات وMaster Sheet.


## v1.2
- كل قسم يعرض المواد الخاصة به داخل بطاقة مستقلة.
- تجميع المواد حسب المراحل الأربع.
- إظهار عدد المواد في كل قسم وكل مرحلة.
- الإبقاء على إدارة وإضافة المواد مع ربطها بالقسم والمرحلة.


## v1.3
- جعل لكل قسم مجموعة مواد خاصة به داخل بطاقة القسم.
- تجميع مواد كل قسم حسب المرحلة الدراسية.
- في إدخال الدرجات، اختيار القسم والمرحلة يعرض فقط مواد القسم والمرحلة المحددين.
- منع تسجيل مادة لا تنتمي إلى قسم الطالب ومرحلته.
