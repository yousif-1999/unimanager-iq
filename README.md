# UniManager IQ — MVP

نسخة تجريبية أولى لنظام إدارة الكليات والمعاهد.

## التشغيل

يمكن تشغيل المشروع مباشرة بفتح `index.html` في المتصفح، أو نشره على GitHub Pages.

بيانات الدخول التجريبية:
- Username: `admin`
- Password: `admin123`

## الوحدات الحالية

- لوحة تحكم وإحصاءات.
- إدارة الطلبة: إضافة/تعديل/حذف/بحث وتصفية.
- إدارة الأقساط وتسجيل الدفعات.
- استيراد Excel.
- تصدير Excel وتقارير الحسابات.
- صفحة تمهيدية للدرجات.

## الخطوة التالية في الإنتاج

هذه نسخة MVP تعمل محليًا باستخدام LocalStorage. للاستخدام الحقيقي من أكثر من موظف يجب إضافة Backend + PostgreSQL + نظام مصادقة وصلاحيات وتدقيق عمليات، ثم ربط التطبيق بخدمة استضافة آمنة.
